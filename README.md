# JOBLEX - Academia-Industry Collaboration Portal
**Ministry of Ayush / All India Institute of Ayurveda | Problem Statement ID: 26044**

A unified 3D platform for skill mapping, interactive gamified career roadmaps with anti-decay protection, AI resume gap analysis, industry internships, and bilateral curriculum modernization.

---

## ⚡ Quick Start (1-Click)

On Windows, simply double-click:
```bash
run_all.bat
```
This automatically starts the Python server and opens **`http://localhost:5000`** in your default web browser.

---

## 🛠️ Manual Run Instructions

1. Open your terminal in the project directory:
   ```bash
   cd mainsihrepo
   ```
2. (Optional) Install Python requirements:
   ```bash
   pip install -r backend/requirements.txt
   ```
3. Run the server:
   ```bash
   python backend/app.py
   ```
4. Open **`http://localhost:5000`** in your browser.

## 🧭 Platform Portals & Features

* **Welcome & Landing Hub (`index.html`):** Ambient 3D starfield particles, platform features, stats strip, and role gateway cards.
* **Unified Auth & 1-Click Judge Demos (`auth.html`):** Instant login buttons for **Student**, **Academic Dean**, and **Industry HR**.
* **Student Portal (`student.html`):**
  * **Interactive Career Roadmap:** Anti-decay point preservation, milestone tasks with live XP calculation, and daily streak check-in freeze.
  * **AI Resume & Skill Gap Analyzer:** Benchmarking student CVs against live pharmaceutical and Ayush industrial standards (GLP, HPTLC, Phytochemistry).
  * **Quiz Arena:** Interactive 5-question competency tests with XP rewards.
  * **Opportunities Board:** Internships, full-time jobs, and hackathons with category filters.
  * **Zulu AI Companion:** 24/7 Context-aware AI career guidance counselor.
  * **Skill Constellation:** Interactive 2D canvas map of acquired skills.
  * **Verified Portfolio:** Profile with credentials and AIIA certifications.
* **Academy Portal (`academy.html`):** Student Progress Matrix, AI-Driven Syllabus Modernization (NEP-2020), FDP programs, and bilateral MoUs.
* **Industry Portal (`industry.html`):** Pre-screened candidate discovery with skill match scores, opportunity publishing, and direct skill demand submissions to academic councils.

## 🚀 Deploying to Vercel

This repository is built with pure HTML5, CSS3, and JavaScript, making deployment instant with zero build configuration:

1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository (`ashaydongre27/mainsihrepo`).
4. Click **"Deploy"** (no build settings required).
